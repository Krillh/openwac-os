OpenWAC OS, or just "WACOS", is the standard kernel, and operating system, and
shell OpenWAC. WACOS is 100% human-written and is purposefully multilingual as
an exercise in learning new programming languages.

WACOS is made of 3 modules: `kernel`, `os`, and `shell`.
